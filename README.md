## Run locally
Server:
  cd server
  npm install
  Create .env from .env.example
  npm run dev

Client:
  cd client
  npm install
  npm run dev

## Tests
Server:
  cd server && npm test

Client:
  cd client && npm test

## Deployment
- Backend — Render/Heroku: set `MONGO_URI`, `JWT_SECRET`.
- Frontend — Vercel/Netlify: set VITE_API_URL to backend URL.
